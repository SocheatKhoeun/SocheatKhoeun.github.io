# Socheat Khoeun — Portfolio

Personal portfolio site, live at **https://socheatkhoeun.github.io/**.

Static HTML/CSS/JS — no build step. Hosted on GitHub Pages.

## Structure
```
index.html            page markup
assets/css/style.css  styles (light/dark themes)
assets/js/main.js     skills & projects data, live GitHub repo feed, interactions
```

## Updating content
Edit the `SKILLS` and `PROJECTS` arrays at the top of `assets/js/main.js`.

## Run locally
```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
